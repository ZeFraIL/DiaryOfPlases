# תיאור המחלקה: Search

________________________________________
## 1. מידע כללי
*   **שם המחלקה:** `Search`
*   **סוג:** אקטיביטי (Activity)
*   **ייעוד:** מסך זה פועל כדפדפן אינטרנט קטן בתוך האפליקציה. תפקידו העיקרי הוא לעזור למשתמש לחפש מידע על מקום בגוגל ו"ללכוד" את כתובת האינטרנט (URL) של הדף שהוא מצא.
*   **אינטראקציה:** יורשת מ-`BaseActivity`. היא נקראת בדרך כלל על ידי `AddPlace`. בסיום, היא מחזירה את כתובת ה-URL חזרה למסך שפתח אותה.

________________________________________
## 2. משתנים (שדות המחלקה)
| שם | סוג | מטרה | איפה נעשה בו שימוש |
| :--- | :--- | :--- | :--- |
| `et` | `EditText` | תיבת הטקסט שבה מוקלדת שאילתת החיפוש. | מאותחלת ב-`initElements()`, נקראת ב-`goSearch()`. |
| `wvs` | `WebView` | הרכיב שמציג אתרי אינטרנט אמיתיים. | משמש להצגת גוגל ולניווט. |
| `stUrl` | `String` | שומר את מונח החיפוש או את כתובת ה-URL הנוכחית. | משמש לטעינת דף האינטרנט. |
| `GOOGLE_SEARCH_URL` | `String` | כתובת הבסיס לחיפושים בגוגל. | משולבת עם מונח החיפוש. |

*   **WebView:** "חלון" מיוחד באנדרואיד שיכול לטעון ולהציג תכני אינטרנט בדיוק כמו דפדפן (כמו כרום).
*   **Intent Extra:** דרך לשלוח נתונים (כמו שם המקום) בין שני מסכים.

________________________________________
## 3. מתודות המחלקה

### שם המתודה: `onCreate`
*   **סוג:** `protected`
*   **לוגיקה:** קובעת את העיצוב וקוראת ל-`initElements()`.
*   **מתי נקראת:** כאשר המשתמש לוחץ על כפתור "חיפוש קישור" ב-`AddPlace`.

### שם המתודה: `initElements`
*   **סוג:** `private`
*   **לוגיקה:**
    1. מקבלת את מונח החיפוש (למשל, "מגדל אייפל") מהמסך הקודם.
    2. שמה את המונח הזה בתיבת הטקסט.
    3. מגדירה את ה-`WebView` (מפעילה JavaScript כדי שאתרי אינטרנט יעבדו כראוי).
    4. מבצעת חיפוש אוטומטי בגוגל עבור המונח הזה.
*   **מתי נקראת:** במהלך הגדרת המסך הראשונית.

### שם המתודה: `goSearch`
*   **סוג:** `public`
*   **פרמטרים:** `View view` (כפתור החיפוש).
*   **לוגיקה:**
    1. קוראת את הטקסט שנמצא בתיבת הטקסט.
    2. משתמשת בעוזר הקולי כדי לומר "Search now for...".
    3. מורה ל-`WebView` לטעון דף חיפוש חדש של גוגל עם הטקסט הזה.
*   **מתי נקראת:** כאשר המשתמש מקליד משהו באופן ידני ולוחץ על "Search".

### שם המתודה: `backWithLink`
*   **סוג:** `public`
*   **לוגיקה:**
    1. מקבלת את כתובת האינטרנט הנוכחית (URL) של הדף שהמשתמש מסתכל עליו.
    2. יוצרת "אינטנט תוצאה" המכיל את כתובת ה-URL הזו.
    3. שולחת אותה חזרה למסך הקודם וסוגרת את מסך החיפוש.
*   **מתי נקראת:** כאשר המשתמש לוחץ על הכפתור כדי "לשמור את הקישור הזה" לרשומת המקום.

### מחלקה פנימית: `MyWebViewClient`
*   **מטרה:** מחלקה קטנה זו מבטיחה שכאשר לוחצים על קישור בתוך הדפדפן, הוא יישאר *בתוך* האפליקציה שלנו במקום לפתוח את דפדפן הכרום החיצוני של הטלפון.

________________________________________
## 4. מחזור חיים
*   **onCreate():** מאתחלת את הדפדפן ומתחילה את החיפוש הראשון.
*   **onDestroy():** יורשת מ-BaseActivity.

________________________________________
## 5. אינטראקציה עם הממשק (UI)
*   **EditText:** להזנת מונחי חיפוש.
*   **WebView:** האזור העיקרי לגלישה.
*   **כפתורים:** "Search" (לרענון הדף) ו-"Back with Link" (להחזרת התוצאה).

________________________________________
## 6. אינטראקציה עם רכיבים אחרים
*   **Intent:** מקבלת שאילתה דרך `EXTRA_SEARCH_QUERY` ומחזירה URL דרך `EXTRA_RESULT_URL`.
*   **setResult():** זו הדרך שבה האפליקציה אומרת למסך הקודם: "סיימתי, הנה הנתונים שביקשת".

________________________________________
## 7. לוגיקה כללית של המחלקה
המחלקה היא כמו **מתווך**. אתם אומרים לה מה אתם רוצים למצוא, היא פותחת עבורכם את האינטרנט, אתם גולשים עד שאתם מוצאים את הדף הנכון, ואז אתם "תופסים" את הקישור לאותו דף ומביאים אותו חזרה ליומן שלכם.

________________________________________
## 8. הסבר פשוט
**הסבר במילים פשוטות:**
חשבו על מחלקת `Search` כעל **זכוכית מגדלת מובנית** לאינטרנט.
*   אתם אומרים לזכוכית המגדלת מה אתם מחפשים.
*   היא מראה לכם את תוצאות החיפוש בגוגל.
*   כשאתם מוצאים את האתר המושלם, אתם אומרים לאפליקציה: "זכרי את הכתובת הזו!"
*   האפליקציה לוקחת את הכתובת הזו ומדביקה אותה בתוך רשומת המקום שלכם.

**אנלוגיה:** זה כמו **ללכת לספרייה** כדי למצוא ספר ספציפי. מסך ה-`Search` הוא הטיול לספרייה. ברגע שאתם מוצאים את הספר, אתם רושמים את המיקום שלו (הקישור) וחוזרים הביתה כדי לשים אותו בהערות שלכם.
