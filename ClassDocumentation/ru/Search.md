# Описание класса: Search

________________________________________
## 1. Общая информация
*   **Имя класса:** `Search`
*   **Тип:** Активность (Activity)
*   **Назначение:** Этот экран работает как мини-браузер внутри приложения. Его главная задача — помочь пользователю найти информацию о месте в Google и «захватить» веб-адрес (URL) страницы, которую он нашел.
*   **Взаимодействие:** Наследуется от `BaseActivity`. Обычно вызывается из экрана `AddPlace`. По завершении возвращает найденную ссылку обратно в тот экран, который его открыл.

________________________________________
## 2. Переменные (поля класса)
| Имя | Тип | Назначение | Где используется |
| :--- | :--- | :--- | :--- |
| `et` | `EditText` | Текстовое поле, куда вводится запрос для поиска. | Инициализируется в `initElements()`, считывается в `goSearch()`. |
| `wvs` | `WebView` | Компонент, отображающий реальные веб-сайты. | Используется для вывода Google и навигации. |
| `stUrl` | `String` | Хранит поисковый запрос или текущий URL. | Используется для загрузки веб-страницы. |
| `GOOGLE_SEARCH_URL` | `String` | Базовый адрес для поиска в Google. | Соединяется с поисковым запросом. |

*   **WebView:** Специальное «окно» в Android, которое умеет загружать и показывать интернет-контент точно так же, как обычный браузер (Chrome или Safari).
*   **Intent Extra:** Способ передачи данных (например, названия места) между двумя экранами.

________________________________________
## 3. Методы класса

### Имя метода: `onCreate`
*   **Тип:** `protected`
*   **Логика:** Устанавливает макет экрана и вызывает `initElements()`.
*   **Когда вызывается:** Когда пользователь нажимает кнопку поиска ссылки в `AddPlace`.

### Имя метода: `initElements`
*   **Тип:** `private`
*   **Логика:**
    1. Получает поисковый запрос (например, «Эйфелева башня») с предыдущего экрана.
    2. Помещает этот запрос в текстовое поле.
    3. Настраивает `WebView` (включает JavaScript, чтобы сайты работали правильно).
    4. Автоматически запускает поиск в Google по этому запросу.
*   **Когда вызывается:** Во время начальной настройки экрана.

### Имя метода: `goSearch`
*   **Тип:** `public`
*   **Параметры:** `View view` (кнопка поиска).
*   **Логика:**
    1. Считывает текст, который сейчас находится в поле ввода.
    2. Голосовой помощник говорит: «Search now for...».
    3. Дает команду `WebView` загрузить новую страницу поиска Google с этим текстом.
*   **Когда вызывается:** Когда пользователь вручную что-то печатает и нажимает «Search».

### Имя метода: `backWithLink`
*   **Тип:** `public`
*   **Логика:**
    1. Получает текущий веб-адрес (URL) страницы, на которую смотрит пользователь.
    2. Создает «результирующий интент», содержащий этот URL.
    3. Отправляет его обратно на предыдущий экран и закрывает окно поиска.
*   **Когда вызывается:** Когда пользователь нажимает кнопку сохранения ссылки для записи в дневнике.

### Внутренний класс: `MyWebViewClient`
*   **Назначение:** Этот небольшой класс гарантирует, что при нажатии на любую ссылку внутри браузера, она откроется *внутри* нашего приложения, а не выкинет пользователя во внешний браузер телефона (Chrome).

________________________________________
## 4. Жизненный цикл
*   **onCreate():** Инициализация браузера и запуск первого поиска.
*   **onDestroy():** Наследуется от BaseActivity.

________________________________________
## 5. Взаимодействие с интерфейсом (UI)
*   **EditText:** Для ввода поисковых запросов.
*   **WebView:** Основная область для просмотра интернета.
*   **Кнопки:** «Search» (обновить страницу) и «Back with Link» (вернуть результат).

________________________________________
## 6. Взаимодействие с другими компонентами
*   **Intent:** Получает запрос через `EXTRA_SEARCH_QUERY` и возвращает URL через `EXTRA_RESULT_URL`.
*   **setResult():** Так приложение сообщает предыдущему экрану: «Я закончил, вот данные, которые ты просил».

________________________________________
## 7. Общая логика класса
Этот класс — как **посредник**. Ты говоришь ему, что хочешь найти, он открывает для тебя интернет, ты бродишь по сайтам, пока не найдешь нужный, а затем «хватаешь» ссылку на эту страницу и приносишь её обратно в свой дневник.

________________________________________
## 8. Упрощенное объяснение
**Объяснение простыми словами:**
Представь, что класс `Search` — это **встроенное увеличительное стекло** для интернета.
*   Ты говоришь стеклу, что именно ты ищешь.
*   Оно показывает тебе результаты поиска Google.
*   Когда ты находишь идеальный сайт, ты говоришь приложению: «Запомни этот адрес!».
*   Приложение берет этот адрес и вставляет его в твою запись о месте.

**Аналогия:** Это как **сходить в библиотеку**, чтобы найти конкретную книгу. Экран `Search` — это сам поход в библиотеку. Когда ты нашел книгу, ты выписываешь её адрес (ссылку) и возвращаешься домой, чтобы записать в свои заметки.
