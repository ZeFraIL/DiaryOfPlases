# Описание класса: MyLocation

________________________________________
## 1. Общая информация
*   **Имя класса:** `MyLocation`
*   **Тип:** Активность (Activity)
*   **Назначение:** Этот экран отвечает за получение текущих географических координат пользователя (широты и долготы) с помощью GPS или мобильной сети телефона.
*   **Взаимодействие:** Наследуется от `BaseActivity`. Обычно запускается из экрана `AddPlace`. Как только местоположение найдено, класс немедленно возвращает координаты и закрывается.

________________________________________
## 2. Переменные (поля класса)
| Имя | Тип | Назначение | Где используется |
| :--- | :--- | :--- | :--- |
| `fusedLocationClient` | `FusedLocationProviderClient` | Основной инструмент для взаимодействия с сервисами геолокации Google. | Инициализируется в `onCreate()`, используется в `getCurrentLocation()`. |
| `requestPermissionLauncher` | `ActivityResultLauncher` | Обрабатывает запрос разрешений на доступ к местоположению у пользователя. | Запускается в `checkPermissionAndGetLocation()`. |

*   **FusedLocationProviderClient:** Компонент сервисов Google Play, который объединяет данные GPS, Wi-Fi и мобильных сетей для получения наиболее точных координат при минимальном расходе батареи.
*   **Широта / Долгота:** Числовые координаты, которые точно указывают на любую точку на планете.

________________________________________
## 3. Методы класса

### Имя метода: `onCreate`
*   **Тип:** `protected`
*   **Логика:**
    1. Настраивает клиент местоположения (`fusedLocationClient`).
    2. Сразу запускает процесс проверки разрешений и получения координат.
*   **Когда вызывается:** Когда пользователь нажимает кнопку «GPS» на экране добавления места.

### Имя метода: `checkPermissionAndGetLocation`
*   **Тип:** `private`
*   **Логика:** Проверяет, есть ли у приложения разрешение `ACCESS_FINE_LOCATION`.
    *   Если да: вызывает `getCurrentLocation()`.
    *   Если нет: запрашивает разрешение у пользователя.
*   **Когда вызывается:** Автоматически при создании экрана.

### Имя метода: `getCurrentLocation`
*   **Тип:** `private`
*   **Логика:**
    1. Запрашивает у системы «последнее известное местоположение» устройства.
    2. Если местоположение найдено:
        *   Извлекает широту и долготу.
        *   Формирует их в одну строку через звездочку (например, «32.0853*34.7818»).
        *   Отправляет эту строку обратно на предыдущий экран через `Intent`.
        *   Закрывает текущий экран.
    3. Если местоположение не найдено (например, GPS выключен), показывает сообщение об ошибке.
*   **Когда вызывается:** Сразу после подтверждения разрешений.

________________________________________
## 4. Жизненный цикл
*   **onCreate():** Немедленно начинает поиск местоположения.
*   **onDestroy():** Наследуется от BaseActivity.

________________________________________
## 5. Взаимодействие с интерфейсом (UI)
*   У этого класса практически нет видимого интерфейса, так как он работает очень быстро в фоне и сразу закрывается после выполнения задачи.

________________________________________
## 6. Взаимодействие с другими компонентами
*   **Google Play Services:** Использует `fusedLocationClient` для общения с аппаратным GPS-модулем телефона.
*   **Intent:** Возвращает строку с координатами в `AddPlace` через метод `setResult(RESULT_OK, ...)`.

________________________________________
## 7. Общая логика класса
Этот класс — **узкоспециализированный инструмент**. Он похож на человека, который выбегает из дома с компасом, определяет, где находится, записывает это на бумажку, возвращается, отдает бумажку тебе и уходит. Он не остается открытым, его единственная цель — доставить координаты.

________________________________________
## 8. Упрощенное объяснение
**Объяснение простыми словами:**
Представь, что класс `MyLocation` — это **цифровой компас**.
*   Когда ты просишь определить местоположение, приложение «будит» этот компас.
*   Компас связывается со спутниками в космосе, чтобы узнать твои точные цифры.
*   Как только цифры получены, он передает их тебе и снова «засыпает», чтобы не тратить заряд батареи.

**Аналогия:** Это как **поставить булавку** на цифровой карте. Приложение находит точную точку, куда упала булавка, и сообщает тебе секретный код (координаты) этой точки.
