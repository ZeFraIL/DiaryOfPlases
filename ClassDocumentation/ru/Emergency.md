# Описание класса: Emergency

________________________________________
## 1. Общая информация
*   **Имя класса:** `Emergency`
*   **Тип:** Активность (Activity)
*   **Назначение:** Этот экран предоставляет пользователю возможность быстро позвонить в экстренные службы (Полиция, Скорая помощь, Пожарная служба) прямо из приложения.
*   **Взаимодействие:** Наследуется от `BaseActivity`. Взаимодействует с системным приложением «Телефон» через интенты (Intents) и требует специальных системных разрешений.

________________________________________
## 2. Переменные (поля класса)
| Имя | Тип | Назначение | Где используется |
| :--- | :--- | :--- | :--- |
| `requestPermissionLauncher` | `ActivityResultLauncher` | Инструмент для запроса у пользователя разрешения на совершение звонков. | Инициализируется как поле класса, запускается в `requestCallPermission()`. |

*   **Разрешения:** Совершение звонков автоматически считается «опасным» разрешением в Android, поэтому приложение обязано спросить явное согласие пользователя во время работы.

________________________________________
## 3. Методы класса

### Имя метода: `onCreate`
*   **Тип:** `protected`
*   **Логика:**
    1. Устанавливает макет интерфейса (`activity_emergency.xml`).
    2. Вызывает `requestCallPermission()` для проверки прав на звонки.
    3. Настраивает три кнопки, которые вызывают метод `callNow()` с номерами «100», «101» и «102».
*   **Когда вызывается:** При выборе пункта «Emergency» в меню.

### Имя метода: `requestCallPermission`
*   **Тип:** `private`
*   **Логика:** Проверяет, дано ли уже разрешение `CALL_PHONE`. Если нет — запускает стандартное окно запроса Android.
*   **Когда вызывается:** Автоматически при создании экрана.

### Имя метода: `callNow`
*   **Тип:** `private`
*   **Параметры:** `String phoneNumber` (номер телефона, например, «100»).
*   **Логика:**
    1. Голосовой помощник озвучивает фразу «Calling now...».
    2. Проверяет наличие разрешения.
    3. Если разрешение есть, создает «намерение» (Intent) с действием `ACTION_CALL` и номером телефона.
    4. Запускает активность, которая открывает системный интерфейс звонка и начинает набор номера.
*   **Когда вызывается:** При нажатии на любую из кнопок экстренного вызова.

________________________________________
## 4. Жизненный цикл
*   **onCreate():** Инициализация интерфейса и работа с разрешениями.
*   **onDestroy():** Наследуется от `BaseActivity`.

________________________________________
## 5. Взаимодействие с интерфейсом (UI)
*   **Кнопки:** `bCallPolice`, `bCallAmbulance`, `bCallFire`.
*   **Событие:** Нажатие на эти кнопки запускает процесс вызова.

________________________________________
## 6. Взаимодействие с другими компонентами
*   **Intent (ACTION_CALL):** Используется для связи с системным «номеронабирателем» ОС Android.
*   **Uri:** Используется для форматирования номера телефона в виде `tel:100`.

________________________________________
## 7. Общая логика класса
Класс спроектирован для **максимальной скорости**. Он запрашивает разрешение сразу при открытии. При нажатии на кнопку вызов инициируется мгновенно. Также используется голосовое подтверждение, чтобы пользователь понимал, что происходит.

________________________________________
## 8. Упрощенное объяснение
**Объяснение простыми словами:**
Представь, что класс `Emergency` — это **панель быстрого набора** на общественном телефоне.
*   На ней есть три большие кнопки для самых важных служб.
*   Прежде чем ты сможешь ими воспользоваться, телефон спросит: «Ты разрешаешь этому приложению звонить?».
*   Как только ты ответишь «Да», одно нажатие на кнопку сразу начнет звонок.

**Аналогия:** Это как **тревожная кнопка** под стеклом. Ты разбиваешь стекло (даешь разрешение) и жмешь на кнопку, чтобы мгновенно получить помощь.
