# Описание класса: Guide

________________________________________
## 1. Общая информация
*   **Имя класса:** `Guide`
*   **Тип:** Активность (Activity)
*   **Назначение:** Этот экран представляет собой руководство пользователя для приложения. Он отображает различные разделы справки, которые можно раскрывать или сворачивать (по принципу «аккордеона»).
*   **Взаимодействие:** Наследуется от `BaseActivity`. Считывает текстовые файлы из внутренних ресурсов приложения (`res/raw`) и динамически создает кнопки и текстовые поля на экране.

________________________________________
## 2. Переменные (поля класса)
| Имя | Тип | Назначение | Где используется |
| :--- | :--- | :--- | :--- |
| `LL` | `LinearLayout` | Вертикальный контейнер, в который добавляются кнопки и текст. | В `initViews()` и `buildAccordion()`. |
| `files` | `List<String>` | Список имен файлов, содержащих контент руководства. | Заполняется в `buildListOfFiles()`. |
| `btns` | `List<Button>` | Список кнопок, созданных для каждого раздела. | В `buildAccordion()` и `onClick()`. |
| `tvs` | `List<TextView>` | Список текстовых полей, в которых отображается текст справки. | В `buildAccordion()` и `toggleSection()`. |

*   **List:** Динамическая коллекция (список), используемая для хранения нескольких элементов одного типа.
*   **LinearLayout:** Разметка, которая располагает элементы друг за другом (в данном случае — в столбик).

________________________________________
## 3. Методы класса

### Имя метода: `onCreate`
*   **Тип:** `protected`
*   **Логика:**
    1. Устанавливает макет экрана.
    2. Инициализирует контейнер (`LL`).
    3. Загружает список доступных имен файлов из ресурсов.
    4. Строит визуальный интерфейс («аккордеон»).
*   **Когда вызывается:** При выборе пункта «Guide» в меню.

### Имя метода: `buildAccordion`
*   **Тип:** `private`
*   **Логика:**
    1. Проходит циклом по списку имен файлов.
    2. Для каждого файла создает новую кнопку (`Button`) с текстом «Guide's part #...».
    3. Создает под каждой кнопкой текстовое поле (`TextView`), устанавливает его видимость в `GONE` (скрыто) и добавляет оба элемента на экран.
*   **Когда вызывается:** Во время инициализации в `onCreate`.

### Имя метода: `toggleSection`
*   **Тип:** `private`
*   **Параметры:** `int index` (номер части, на которую нажали).
*   **Логика:**
    1. Проверяет, видимо ли сейчас текстовое поле под этим индексом.
    2. Если видимо — скрывает его (`GONE`).
    3. Если скрыто — загружает текст из файла, показывает его (`VISIBLE`) и просит голосового помощника озвучить содержимое.
*   **Когда вызывается:** При нажатии пользователем на одну из кнопок руководства.

### Имя метода: `loadContentFromFile`
*   **Тип:** `private`
*   **Возвращаемое значение:** `String` (полный текст файла).
*   **Логика:**
    1. Находит внутренний ID файла по его имени.
    2. Открывает файл как поток данных (`InputStream`).
    3. С помощью `BufferedReader` читает файл построчно и объединяет в одну длинную строку.
*   **Что важно понимать:** Если файл не найден или не читается, приложение покажет ошибку через «Toast».

________________________________________
## 4. Жизненный цикл
*   **onCreate():** Настройка динамического интерфейса.
*   **onDestroy():** Наследуется от `BaseActivity`.

________________________________________
## 5. Взаимодействие с интерфейсом (UI)
*   **LinearLayout:** Вертикальная «стопка», в которой лежат все элементы.
*   **Динамические кнопки:** Создаются прямо в коде, служат заголовками разделов.
*   **Динамические TextView:** Создаются в коде, появляются и исчезают для отображения текста.

________________________________________
## 6. Взаимодействие с другими компонентами
*   **Ресурсы (R.raw):** Приложение читает локальные текстовые файлы, хранящиеся в папке `raw`.
*   **TtsManager:** Используется для обеспечения аудио-версии руководства.

________________________________________
## 7. Общая логика класса
Класс работает как **динамический генератор**. Вместо того чтобы вручную рисовать 10 кнопок в XML-файле, он смотрит на список файлов (`guide_all`) и создает ровно столько кнопок, сколько файлов существует. Это экономит память, так как текст загружается только тогда, когда пользователь действительно нажал на раздел.

________________________________________
## 8. Упрощенное объяснение
**Объяснение простыми словами:**
Представь, что класс `Guide` — это **набор ящиков в комоде**.
*   На каждом ящике есть этикетка (кнопка).
*   Когда ты открываешь ящик (нажимаешь кнопку), приложение «достает» оттуда бумагу с текстом и показывает её тебе.
*   Если ты закрываешь ящик, бумага прячется, чтобы не загромождать стол.

**Аналогия:** Это как **раскладная карта**. Ты разворачиваешь только ту часть, на которую смотришь сейчас, чтобы вся карта не закрывала тебе обзор.
