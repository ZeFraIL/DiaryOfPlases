# Описание класса: MainChoise

________________________________________
## 1. Общая информация
*   **Имя класса:** `MainChoise`
*   **Тип:** Активность (Activity)
*   **Назначение:** Этот экран выступает в роли главного меню или «центра управления» приложением. Он позволяет пользователю выбрать одну из трех основных функций: добавление нового места, просмотр сохраненных мест или чтение общей информации.
*   **Взаимодействие:** Наследуется от `BaseActivity`. Служит отправной точкой для перехода к экранам `AddPlace`, `ViewPlaces` и `OnlyInfo`.

________________________________________
## 2. Переменные (поля класса)
В этом классе нет собственных постоянных переменных. Он использует временные объекты внутри своих методов.

________________________________________
## 3. Методы класса

### Имя метода: `onCreate`
*   **Тип:** `protected`
*   **Логика:**
    1. Устанавливает макет интерфейса (`activity_main_choise.xml`).
    2. Назначает обработчики нажатий для трех кнопок:
        *   «Add Place» -> вызывает `buildDialog` для перехода к `AddPlace`.
        *   «View Places» -> вызывает `buildDialog` для перехода к `ViewPlaces`.
        *   «Info» -> вызывает `buildDialog` для перехода к `OnlyInfo`.
*   **Когда вызывается:** Автоматически после того, как пользователь вошел в приложение.

### Имя метода: `buildDialog`
*   **Тип:** `public`
*   **Параметры:**
    | Имя | Тип | Описание |
    | :--- | :--- | :--- |
    | `title` | `String` | Вопрос, который будет показан (например, «Add place?»). |
    | `toGo` | `Class<?>` | Класс активности, которую нужно открыть при ответе «Да». |
*   **Логика:**
    1. Голосовой помощник озвучивает заголовок (вопрос).
    2. Показывает всплывающее окно (`AlertDialog`) с кнопками «Yes» и «No».
    3. Если нажато «Yes», создается `Intent` и запускается выбранная активность.
    4. Если нажато «No», окно просто закрывается.
*   **Зачем нужен диалог?** Это предотвращает случайные нажатия и помогает пользователям, использующим голосовое управление, подтвердить свой выбор.

________________________________________
## 4. Жизненный цикл
*   **onCreate():** Настройка кнопок меню.
*   **onDestroy():** Наследуется от `BaseActivity`.

________________________________________
## 5. Взаимодействие с интерфейсом (UI)
*   **Кнопки:** `bAddPlace`, `bViewPlaces`, `bInfo`.
*   **AlertDialog:** Используется для подтверждения каждого выбора пользователя.

________________________________________
## 6. Взаимодействие с другими компонентами
*   **Intent:** Используется для перехода к выбранной функции.
*   **TtsManager:** Используется через метод `speak()` для озвучивания меню.

________________________________________
## 7. Общая логика класса
Этот класс — **регулировщик движения**. Он сам не обрабатывает данные, он просто спрашивает пользователя: «Куда ты хочешь пойти?» и открывает нужную дверь.

________________________________________
## 8. Упрощенное объяснение
**Объяснение простыми словами:**
Представь, что класс `MainChoise` — это **главный коридор** в доме.
*   В коридоре три большие двери с вывесками.
*   Прежде чем ты откроешь дверь, голос спрашивает: «Ты уверен, что хочешь зайти сюда?».
*   Если ты говоришь «Да», ты входишь в комнату. Если «Нет» — остаешься в коридоре.

**Аналогия:** Это как **главное меню** в игре или приложении для просмотра фильмов. Ты выбираешь: «Начать игру» (Добавить место), «Выбор уровня» (Посмотреть места) или «Настройки/Инфо» (Инфо).
