# Описание класса: PlaceAdapter

________________________________________
## 1. Общая информация
*   **Имя класса:** `PlaceAdapter`
*   **Тип:** Адаптер для RecyclerView
*   **Назначение:** Этот класс выступает в роли «моста» (или переводчика) между списком объектов `Place` (данными) и `RecyclerView` (визуальным списком на экране). Его задача — взять каждое место из списка и определить, как оно должно выглядеть в одной строке списка.
*   **Взаимодействие:** Тесно работает с `ViewPlaces` (экраном) и `Place` (данными). Также использует **интерфейс** `OnItemClickListener`, чтобы сообщить экрану, когда пользователь нажал на конкретный элемент.

________________________________________
## 2. Переменные (поля класса)
| Имя | Тип | Назначение | Где используется |
| :--- | :--- | :--- | :--- |
| `places` | `List<Place>` | Исходный список всех мест, которые нужно отобразить. | Используется в `onBindViewHolder()` и `getItemCount()`. |
| `listener` | `OnItemClickListener` | Объект, который обрабатывает нажатия на строки списка. | Используется в методе `bind()` внутри ViewHolder. |

*   **Adapter (Адаптер):** Шаблон проектирования, используемый для соединения несовместимых интерфейсов. В Android он соединяет данные с прокручиваемым списком.
*   **Interface (Интерфейс):** «Контракт», который определяет, какие методы должен иметь другой класс (похоже на свод правил).

________________________________________
## 3. Методы класса

### Имя метода: `onCreateViewHolder`
*   **Тип:** `public`
*   **Возвращаемое значение:** `PlaceViewHolder`
*   **Логика:**
    1. Использует `LayoutInflater`, чтобы «раздуть» (превратить XML в код) разметку для одной строки (`list_item_place.xml`).
    2. Возвращает новый объект `PlaceViewHolder`, который хранит ссылки на элементы этой строки.
*   **Когда вызывается:** Когда `RecyclerView` нужно создать новую строку (например, при первой загрузке списка).

### Имя метода: `onBindViewHolder`
*   **Тип:** `public`
*   **Логика:**
    1. Находит конкретный объект `Place` для текущей позиции в списке.
    2. Передает эти данные в `ViewHolder`, чтобы обновить экран.
*   **Когда вызывается:** Когда строка становится видимой и ей нужно показать конкретное содержимое (например, при прокрутке).

### Имя метода: `getItemCount`
*   **Тип:** `public`
*   **Возвращаемое значение:** `int` (общее количество мест).
*   **Логика:** Сообщает `RecyclerView`, сколько всего элементов в списке.

### Внутренний класс: `PlaceViewHolder`
*   **Назначение:** Этот класс служит «держателем» для визуальных элементов внутри одной строки (например, текста заголовка). Это избавляет приложение от постоянного поиска элементов через `findViewById`, что делает прокрутку очень плавной.
*   **Метод `bind`:** Устанавливает текст названия места и настраивает слушатель нажатий на всю строку целиком.

________________________________________
## 4. Жизненный цикл
Адаптер управляется компонентом `RecyclerView`. Он «живет» до тех пор, пока список находится на экране.

________________________________________
## 5. Взаимодействие с интерфейсом (UI)
*   **LayoutInflater:** Превращает XML-файлы в объекты Java View.
*   **TextView:** Отображает название места в списке.
*   **ItemView:** Вся строка целиком, на которую можно нажать.

________________________________________
## 6. Взаимодействие с другими компонентами
*   **RecyclerView:** Основной компонент списка, который управляет адаптером.
*   **Place:** Источник данных.
*   **OnItemClickListener:** Передает информацию о нажатиях обратно в `ViewPlaces`.

________________________________________
## 7. Общая логика класса
Представь, что у тебя есть колода карт (`places`). Есть человек (`PlaceAdapter`), чья задача — брать по одной карте и вставлять её в специальную рамку (`ViewHolder`). Затем рамка вешается на стену (`RecyclerView`). Если ты прокручиваешь список, человек вынимает карту из рамки, которая ушла за край, и вставляет туда новую карту, чтобы повесить её обратно на стену.

________________________________________
## 8. Упрощенное объяснение
**Объяснение простыми словами:**
Представь, что `PlaceAdapter` — это **оформитель меню**.
*   Данные — это **список блюд** (названия мест).
*   `ViewHolder` — это **пустая карточка меню**.
*   `PlaceAdapter` берет название и аккуратно записывает его в карточку (`bind`).
*   `RecyclerView` — это **подставка для меню** на столе, которая показывает все карточки посетителю.

**Аналогия:** Это как **переводчик** на конференции. Докладчик (данные) говорит на одном языке, а переводчик (адаптер) превращает это в визуальный язык (список на экране), чтобы аудитория (пользователь) могла всё понять.
