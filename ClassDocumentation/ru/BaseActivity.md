# Описание класса: BaseActivity

________________________________________
## 1. Общая информация
*   **Имя класса:** `BaseActivity`
*   **Тип:** Абстрактная активность (Базовый класс)
*   **Назначение:** Это «родительский» класс, от которого наследуются почти все остальные экраны (Activity) приложения. Он содержит общую логику, которая нужна везде: управление главным меню, навигация между экранами и голосовой помощник.
*   **Взаимодействие:** Служит шаблоном для других классов (например, `AddPlace`, `ViewPlaces`). Также взаимодействует с `TtsManager` для воспроизведения звука.

________________________________________
## 2. Переменные (поля класса)
| Имя | Тип | Назначение | Где используется |
| :--- | :--- | :--- | :--- |
| `isService` | `boolean` | Хранит состояние голосового помощника (вкл/выкл). | В методе `speak()` и при выборе пунктов меню. |
| `ttsManager` | `TtsManager` | Объект для работы с системой перевода текста в речь. | Инициализируется в `onCreate()`, используется в `speak()`. |

*   **isService:** Флаг (истина/ложь), который говорит приложению, нужно ли озвучивать действия.
*   **ttsManager:** Инструмент, который превращает текст в человеческую речь.

________________________________________
## 3. Методы класса

### Имя метода: `onCreate`
*   **Тип:** `protected`
*   **Возвращаемое значение:** `void` (ничего не возвращает)
*   **Параметры:**
    | Имя | Тип | Описание |
    | :--- | :--- | :--- |
    | `savedInstanceState` | `Bundle` | Объект для восстановления состояния после перезапуска. |
*   **Логика:**
    1. Вызывает конструктор родительского класса.
    2. Получает экземпляр `TtsManager` для работы со звуком.
*   **Когда вызывается:** Автоматически системой Android при создании экрана.

### Имя метода: `onCreateOptionsMenu`
*   **Тип:** `public`
*   **Возвращаемое значение:** `boolean` (true, если меню должно быть отображено)
*   **Параметры:**
    | Имя | Тип | Описание |
    | :--- | :--- | :--- |
    | `menu` | `Menu` | Объект, в который загружается разметка меню. |
*   **Логика:** Загружает меню из ресурсов (`main.xml`) и делает иконки видимыми.
*   **Когда вызывается:** При открытии экрана для отображения кнопок в верхней панели.

### Имя метода: `onOptionsItemSelected`
*   **Тип:** `public`
*   **Возвращаемое значение:** `boolean`
*   **Параметры:**
    | Имя | Тип | Описание |
    | :--- | :--- | :--- |
    | `item` | `MenuItem` | Конкретный пункт меню, на который нажали. |
*   **Логика:** Проверяет, какая кнопка была нажата (Назад, Выход, Включить голос и т.д.) и выполняет соответствующее действие (закрывает экран, открывает новый или меняет `isService`).
*   **Когда вызывается:** Когда пользователь нажимает на любой пункт в верхнем меню.

### Имя метода: `speak`
*   **Тип:** `protected`
*   **Возвращаемое значение:** `void`
*   **Параметры:**
    | Имя | Тип | Описание |
    | :--- | :--- | :--- |
    | `message` | `String` | Текст, который нужно озвучить. |
*   **Логика:** Если `isService` равен `true`, текст отправляется в `ttsManager` для воспроизведения.
*   **Важно понимать:** Если пользователь выключил озвучку, этот метод ничего не сделает.

________________________________________
## 4. Жизненный цикл (Activity)
*   **onCreate():** Вызывается в самом начале. Здесь мы готовим общий инструмент озвучки.
*   **onDestroy():** Вызывается при уничтожении экрана. Здесь можно было бы выключить озвучку для экономии памяти (сейчас закомментировано).

________________________________________
## 5. Взаимодействие с интерфейсом (UI)
*   Класс работает с **Options Menu** (три точки или кнопки в верхней панели).
*   Обрабатывает нажатия на иконки меню для навигации по всему приложению.

________________________________________
## 6. Взаимодействие с другими компонентами
*   **Intent:** Используется для перехода на экраны `Credits`, `Guide`, `InnerContacts` и `Emergency`.
*   **finish():** Закрывает текущий экран.
*   **finishAffinity():** Полностью завершает работу приложения.

________________________________________
## 7. Общая логика класса
Этот класс выступает в роли «клея». Чтобы не писать код меню в 10 разных файлах, мы пишем его один раз в `BaseActivity`, а остальные классы просто «наследуют» это поведение. Если мы включим озвучку на одном экране, флаг `isService` будет управлять этим и на всех последующих.

________________________________________
## 8. Упрощенное объяснение
**Объяснение простыми словами:**
Представь, что `BaseActivity` — это **универсальный пульт**. Каждый экран приложения — это разный телевизор, но все они используют один и тот же пульт. На этом пульте есть кнопки «Меню», «Назад», «Выход» и кнопка «Голос». Вместо того чтобы давать каждому телевизору свой пульт, мы сделали один главный пульт, который подходит всем.

**Аналогия:** Это как школьная форма. Все ученики её носят, поэтому нам не нужно описывать одежду каждого ученика отдельно. Мы просто говорим «они в форме», и все знают, что у них белая рубашка и темные брюки. `BaseActivity` — это и есть эта «форма» для наших экранов.
