# Описание класса: InnerContacts

________________________________________
## 1. Общая информация
*   **Имя класса:** `InnerContacts`
*   **Тип:** Активность (Activity)
*   **Назначение:** Этот экран является менеджером контактов приложения. Он позволяет пользователю вести собственный список «Внутренних контактов» (сохраненных внутри приложения) и просматривать все контакты, хранящиеся в самом телефоне.
*   **Взаимодействие:** Наследуется от `BaseActivity`. Взаимодействует с системной телефонной книгой через `ContentResolver` и с приватной базой данных приложения через `HelperDB`.

________________________________________
## 2. Переменные (поля класса)
| Имя | Тип | Назначение | Где используется |
| :--- | :--- | :--- | :--- |
| `recyclerViewContacts`| `RecyclerView` | Список для отображения контактов. | Инициализируется в `initViews()`. |
| `progressBar` | `ProgressBar` | Индикатор загрузки при поиске контактов. | В методе `setLoading()`. |
| `helperDB` | `HelperDB` | Доступ к локальной базе данных. | В `displayInnerContacts()`. |
| `currentContact` | `myContact` | Хранит контакт, с которым пользователь работает в данный момент. | Используется в диалоговом окне. |

*   **ContentResolver:** Инструмент Android, позволяющий одному приложению читать данные другого (например, читать контакты из телефонной книги).
*   **myContact:** Пользовательский класс данных, представляющий одного человека (ID, Имя, Телефон, Email, Комментарий).

________________________________________
## 3. Методы класса

### Имя метода: `onCreate`
*   **Тип:** `protected`
*   **Логика:**
    1. Настраивает макет экрана.
    2. Запрашивает разрешения на чтение контактов и совершение звонков.
    3. Настраивает кнопки для переключения между «Внутренними» и «Всеми» контактами.
*   **Когда вызывается:** При выборе пункта «Contacts» в главном меню.

### Имя метода: `displayInnerContacts`
*   **Тип:** `private`
*   **Логика:**
    1. Считывает все записи из таблицы `myContacts` в локальной базе данных.
    2. Превращает строки базы данных в список объектов `myContact`.
    3. Обновляет экран с помощью `ContactAdapter`.
*   **Что важно понимать:** Выполняется в фоновом потоке, чтобы приложение не зависало при чтении данных.

### Имя метода: `displayDeviceContacts`
*   **Тип:** `private`
*   **Логика:**
    1. Запрашивает у системы Android список всех имен и номеров, хранящихся в телефоне.
    2. Форматирует их в виде «Имя: Номер».
    3. Отображает их в том же списке, что и внутренние контакты.

### Имя метода: `showContactDialog`
*   **Тип:** `private`
*   **Логика:**
    1. Создает пользовательское всплывающее окно (`AlertDialog`) с использованием специальной разметки (`mycontact_dialog.xml`).
    2. Предоставляет кнопки для действий: **Позвонить**, **SMS**, **Email**, **Обновить** и **Удалить**.
*   **Когда вызывается:** При нажатии на «Внутренний контакт» в списке.

### Методы `makeCall` / `sendSms` / `sendEmail`
*   **Тип:** `private`
*   **Логика:** Эти методы используют **Intents**, чтобы дать команду системе Android:
    *   Открыть номеронабиратель и начать звонок.
    *   Открыть приложение SMS с готовым текстом.
    *   Открыть почтовое приложение с вписанным адресом.

________________________________________
## 4. Жизненный цикл
*   **onCreate():** Подготовка экрана и списка контактов по умолчанию.
*   **onDestroy():** Наследуется от `BaseActivity`.

________________________________________
## 5. Взаимодействие с интерфейсом (UI)
*   **RecyclerView:** Отображает либо внутренние, либо системные контакты.
*   **Кнопки:** `bInner` (показать контакты приложения), `bTotal` (показать контакты телефона).
*   **Кастомный диалог:** Показывает детальные опции для отдельного контакта.

________________________________________
## 6. Взаимодействие с другими компонентами
*   **ContentResolver:** Для доступа к системным контактам.
*   **HelperDB / SQLite:** Для управления личным списком контактов приложения.
*   **Intent:** Для запуска внешних приложений связи.

________________________________________
## 7. Общая логика класса
Класс предоставляет **двойную телефонную книгу**. Ты можешь отдельно управлять своими «важными» контактами внутри приложения, но при этом иметь быстрый доступ ко всей книге телефона. Для внутренних контактов предусмотрен полный набор инструментов связи (звонок/текст/почта) одним нажатием.

________________________________________
## 8. Упрощенное объяснение
**Объяснение простыми словами:**
Представь, что `InnerContacts` — это **VIP-список** в твоем телефоне.
*   У тебя есть «Основная телефонная книга» (Все контакты).
*   И есть «VIP-список» (Внутренние контакты), созданный специально для этого приложения.
*   Когда ты нажимаешь на человека из VIP-списка, приложение спрашивает: «Хочешь ему позвонить, отправить сообщение или написать письмо?».

**Аналогия:** Это как иметь **дверцу холодильника**, на которую ты вешаешь важные номера. Ты можешь заглянуть в толстую телефонную книгу, если нужно, но самые важные номера всегда под рукой с кнопками быстрого действия.
