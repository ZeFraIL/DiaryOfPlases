# Документация по проекту "DiaryOfPlases"

## 1. Обзор проекта

**DiaryOfPlaces** — это мобильное приложение для Android, представляющее собой личный дневник для сохранения информации о различных местах. Приложение позволяет пользователям аутентифицироваться, добавлять новые места с подробным описанием, фотографией, GPS-координатами и веб-ссылкой, а также управлять списком личных контактов.

---

## 2. Основные компоненты

### 2.1. Активности (Экраны)

#### `Start.java`
- **Макет:** `activity_start.xml`
- **Назначение:** Экран-заставка, который отображается при запуске приложения в течение 5 секунд.
- **Функциональность:** Автоматически переходит на экран `StartChoise` по истечении таймера. Нажатие на экран прерывает таймер и осуществляет переход немедленно.

#### `StartChoise.java`
- **Макет:** `activity_start_choise.xml`
- **Назначение:** Предоставляет пользователю начальный выбор: войти в систему или перейти в информационный раздел.
- **Функциональность:** 
    - Кнопка "Начать" (`startUser`): Переход к экрану `LogOrReg`.
    - Кнопка "Только информация" (`onlyInfo`): Переход к экрану `OnlyInfo`.
    - Меню опций: Доступ к разделам "Кредиты", "Руководство", "Контакты", "Экстренные службы" и включение/выключение голосового сопровождения.

#### `LogOrReg.java`
- **Макет:** `activity_log_or_reg.xml`
- **Назначение:** Экран входа или регистрации пользователя.
- **Функциональность:** 
    - **Режим "Регистрация":** Если файл `mypass.txt` не найден, предлагает пользователю создать и сохранить пароль.
    - **Режим "Вход":** Если файл `mypass.txt` существует, проверяет введенный пароль.
    - **Хранение:** Пароль хранится в виде простого текста во внутреннем хранилище. *Примечание: это небезопасно.*

#### `MainChoise.java`
- **Макет:** `activity_main_choise.xml`
- **Назначение:** Главное меню для аутентифицированного пользователя.
- **Функциональность:**
    - "Добавить место": Переход на `AddPlace`.
    - "Просмотреть места": Переход на `ViewPlaces`.
    - "Информация": Переход на `OnlyInfo`.
    - Перед каждым переходом запрашивается подтверждение через диалоговое окно.

#### `AddPlace.java`
- **Макет:** `activity_add_place.xml`
- **Назначение:** Форма для добавления новой записи о месте.
- **Функциональность:**
    - Позволяет ввести название и комментарий.
    - **Фото:** Запускает приложение камеры для создания снимка (`ACTION_IMAGE_CAPTURE`).
    - **GPS:** Запускает `MyLocation` для получения координат.
    - **Ссылка:** Запускает `Search` для поиска и прикрепления URL.
    - **Сохранение:** Сохраняет все данные, включая изображение в виде `BLOB`, в базу данных SQLite.

#### `ViewPlaces.java`
- **Макет:** `activity_view_places.xml`
- **Назначение:** Отображение списка всех сохраненных мест.
- **Функциональность:**
    - Загружает названия мест из БД и отображает их в `ListView`.
    - При нажатии на элемент списка показывает диалоговое окно с полной информацией: название, комментарий и фотография.

#### `InnerContacts.java`
- **Макет:** `activity_inner_contacts.xml`
- **Назначение:** Центр управления контактами.
- **Функциональность:**
    - Отображает "внутренние" контакты (из БД приложения) или контакты из телефонной книги устройства.
    - Для внутренних контактов позволяет совершать звонки, отправлять SMS, email, а также редактировать и удалять их.

#### `AddInnerContact.java`
- **Макет:** `activity_add_inner_contact.xml`
- **Назначение:** Форма для создания и редактирования "внутренних" контактов.
- **Функциональность:** Работает в режиме добавления (пустая форма) или обновления (форма, заполненная данными контакта).

#### `Search.java`
- **Макет:** `activity_search.xml`
- **Назначение:** Встроенный веб-браузер для поиска и выбора URL.
- **Функциональность:** Использует `WebView` для загрузки Google Поиска с запросом, переданным от `AddPlace`. Возвращает выбранный URL на предыдущий экран.

#### `MyLocation.java`
- **Макет:** `activity_my_location.xml`
- **Назначение:** Получение текущих GPS-координат.
- **Функциональность:** Использует `LocationManager` для получения последнего известного местоположения и немедленно возвращает его на вызвавший экран (`AddPlace`).

### 2.2. Вспомогательные классы и сервисы

#### `HelperDB.java`
- **Назначение:** Класс-помощник для управления базой данных SQLite.
- **Функциональность:** Наследуется от `SQLiteOpenHelper`. Отвечает за создание БД `info.db` и двух таблиц: `Places` и `myContacts`.

#### `Place.java`
- **Назначение:** Класс-модель (POJO) для представления данных об одном месте.
- **Структура:** Содержит поля `placeName`, `placeComment`, `placeImage` (byte[]), `placeLink`, `placeGPS`.

#### `myContact.java`
- **Назначение:** Класс-модель (POJO) для представления данных об одном контакте.
- **Структура:** Содержит поля `contactID`, `contactName`, `contactComment`, `contactPhone`, `contactEmail`.

#### `SpeakService.java`
- **Назначение:** Сервис для синтеза речи (голосовое сопровождение).
- **Функциональность:** Использует `TextToSpeech` для озвучивания текста, полученного через `Intent`. Активируется через меню в большинстве активностей.

## 3. Пользовательский интерфейс (UI)

### 3.1. Файлы разметки (Layouts)

- `activity_start.xml`: Разметка для экрана-заставки.
- `activity_start_choise.xml`: Разметка для экрана начального выбора.
- `activity_log_or_reg.xml`: Разметка для экрана входа/регистрации.
- `activity_main_choise.xml`: Разметка для главного меню.
- `activity_add_place.xml`: Форма добавления места с полями `EditText`, `ImageView` и `Button`.
- `activity_view_places.xml`: Содержит `ListView` для отображения списка мест.
- `activity_inner_contacts.xml`: Содержит `ListView` для контактов и кнопки для переключения режимов.
- `activity_add_inner_contact.xml`: Форма добавления/редактирования контакта.
- `mycontact_dialog.xml`: Кастомная разметка для диалогового окна, отображающего детали контакта и кнопки действий.

### 3.2. Файлы кастомизации дизайна

Эти файлы находятся в папке `res/values/`:

- **`colors.xml`**: Определяет основные цвета, используемые в приложении (цвета фона, текста, акцентные цвета).
- **`strings.xml`**: Содержит все строковые ресурсы. Использование этого файла позволяет легко локализовать приложение на другие языки.
- **`themes.xml` (или `styles.xml`)**: Определяет общую тему приложения, включая базовые атрибуты, такие как цветовая палитра (primary, secondary), стили для кнопок, текстовых полей и других элементов по умолчанию.
